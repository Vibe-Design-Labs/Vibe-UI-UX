# 五段版本规则

公开编号格式：`主版本.阶段版本.功能迭代.设计与交互微调.修复`。当前发布 `0.4.1.2.1`。本次完成 59 个专属场景、75 个词条的完整预览覆盖与维护门槛。

| 例子 | 用途 |
| --- | --- |
| 0.4.0.1.1 → 0.4.0.1.2 | 小修复、单项调整 |
| 0.4.0.1.0 | 完成一组视觉或交互优化，本次叶片与聚光 |
| 0.4.1.0.0 | 新增完整功能 |
| 0.5.0.0.0 | 进入下一阶段 |

编号是五个整数段，不作为浮点数运算。提升某段时重置其后的段。

唯一配置源是 `package.json.intentkitVersion`。构建验证五段格式，替换 HTML 中 `__PROJECT_VERSION__`，并生成 `dist/client/version.json`。网页、更新日志和 Git 标签使用完整公开编号，例如 `v0.4.0.1.0`。

`package.json.version` 保留工具兼容的三段格式，当前为 `0.5.4`。它与公开编号分别管理，不把五段字符串塞入该字段。使用维护 AI 时同时更新 intentkitVersion、兼容 version 与 CHANGELOG.md，并构建检查显示值；源码 ZIP 包含完整配置与更新记录。
