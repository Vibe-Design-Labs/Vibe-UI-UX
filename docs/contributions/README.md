# 社区案例与署名记录

本目录保存社区案例的作者、来源、参数、实现与验证材料。模板见 [TEMPLATE.md](TEMPLATE.md)，参与流程见 [贡献指南](../CONTRIBUTING.md)。

**下面的索引只由维护者在最终接受后更新。** 本地待审提案、Draft PR、测试通过或方向确认都不等于已经收录。此索引不是网站自动读取的社区数据源。

| 已接受案例 | 贡献者约定署名与角色 | 接受的 PR / commit | 官网版本（如适用） |
| --- | --- | --- | --- |

目前此索引尚无已审核的社区贡献记录。现有项目功能不因为新建该目录而改写原有作者归属。

不署名的贡献以「匿名贡献者」或双方约定的表述记录；保留实际复用内容所要求的第三方版权通知。作者链接与公开信息只使用提交者同意公开的范围。

工作台的参数案例保存在 community/cases/，由社区页在合并部署后自动读取；本索引继续保存普通代码 / 文档贡献材料，无需重复登记同一案例。见 [快捷投稿流程](../COMMUNITY_PR.md)。
