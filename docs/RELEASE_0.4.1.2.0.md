## 能力边界

词条正文与来源审校状态不变。五语演示界面并不代表五语正文已经人工审校。看板数据、销售机会、AI 建议与语音状态是本地模拟；不会请求模型、访问麦克风或操作真实业务数据。

Liquid Glass 为 Web 材质近似，3D 为 CSS 3D 与材质示意，没有宣称原生 Apple 渲染或照片级物理渲染。新场景有对应预览，不等于 Compiler 自动理解所有风格；其 5 个配方范围不变。

场景清单、实现位置与截图见 [专属预览说明](PREVIEW_SCENES.md)。
