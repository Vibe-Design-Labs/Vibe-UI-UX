# 0.4.4.0.0 验证记录

本轮针对两项问题：已获得模型返回却笼统提示连接失败；“生成”实际只能匹配既有配方。发布状态为待审 PR，尚未替代 main / 官网。

## 变更结果

- 请求与结果处理分阶段：服务响应、截断、JSON、结构、凭据、预览运行；HTTP 500 明确为“已收到服务端错误”，而非未连接。
- 原按钮改为“理解并匹配配方”。独立生成通道实际请求模型编写 HTML / CSS / JavaScript，不携带候选词条列表。
- 同一个代码 artifact 和参数对象用于隔离预览、参数更新、JSON、独立 Web ZIP 与待审投稿；没有以已有模板替换模型代码。
- 用户未配置密钥时只允许既有本地体验和 JSON 导入；不使用维护者的密钥代用户付费。
- 保持人工审核；生成代码保存在独立案例 JSON 中，Actions 不执行投稿者代码，不自动合并或部署。

## 限制

模型不一定一次返回有效代码，运行成功也不代表行为、语义、性能或安全完成验收。隔离帧没有 CPU 配额；坏代码仍可能卡住浏览器。模型结果不自动注册为正式词条，也不自动获得 React / 视频适配。新生成代码当前提供原生 Web；原有五类模板保留既有 Web / React / 视频输出。

模型密钥只在本页内存，刷新后清除。发送请求后取消、超时或校验失败仍可能被服务商计费。不自动付费重试。
