## 最终行为

- 工作台显示当前生效的模型名称与精确 ID；已连接后有效选择立即改变请求状态。切换取消正在进行的旧请求，点击生成时固定本次快照。
- 代码生成只有一次请求，直接要求原始 HTML / CSS / JavaScript 与有效参数。已有配方匹配保留独立入口，不将其称为原创代码生成。
- 流式接收时区分等待、推理字符数、代码字符数、校验与隔离预览。`kimi-k3` 使用 `high` 和 JSON 模式，上限 16,000 输出 tokens；其他模型不套用 K3 参数。
- 首次响应上限 150 秒，连续无流数据上限 120 秒，总上限 10 分钟；明确结束标记即完成读取。取消传到上游，无自动付费重试或备用模型列表。
- 脱敏回执比较请求与服务报告模型 ID；不同就拒绝，未报告就无法确认。不把响应报告当作独立核验网关内部路由。
- 生成时隐藏旧词库模板及参数，失败仍保持生成状态；主动返回词库后恢复。生成参数和源码在原创效果区查看。
- 本地服务逐块转发已清理的进度及校验后的代码；ZIP 带齐共享模块，不需要 Key 或模型调用。

## 维护者真实 K3 验收

维护者已选择自行在浏览器运行一次，并回传诊断。不读取本机私密 Key 文件，不代跑付费请求。

1. 打开本地 `http://localhost:4174/Vibe-UI-UX/studio.html`，刷新，连接自己的 Key。确认当前模型精确 ID 为 `kimi-k3`。
2. 输入原「风有了形状」需求，点击 **让 AI 编写新效果**。记录进度；不要改模型或重复点击，避免混淆本次调用。
3. 无论成功或失败，复制 **调用模型核对 → 复制调用诊断**，对照 TokenDance 活动记录中的实际模型；不提供 Key、请求头或包含凭据的网络导出文件。
4. 若代码成功，检查六层纸片、入场/呼吸、视差跟随、金色边缘、最多24枚碎片、点击波纹传播、离开复位；五个参数必须真正改变行为。小屏拖动/轻触与减少动态效果分别验证。
5. 导出效果 JSON / Web ZIP，核对同一源码与参数。如果模型 ID 不一致、输出无效或预览不符合需求，先检查诊断或用户自愿提供的效果 JSON；不得声称验收通过。
