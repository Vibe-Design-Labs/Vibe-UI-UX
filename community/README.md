# Community effect cases

The studio submits a validated parameter case through a public GitHub intake form. An Action converts it to one JSON file on an isolated `community/case-N` branch and opens a review PR. Contributors do not need to fork manually or provide an API token.

Only cases merged into main are included in the deployed community gallery. This directory does not accept executable contributor scripts. First release: the five shared component templates. New renderers continue through ordinary code PR review.

Identity comes from the GitHub submission author. Display-name attribution is optional; the GitHub submission remains public. See [the user and maintainer guide](../docs/COMMUNITY_PR.md).
